# DARLY 0.2 — персональный будильник для Android

Исправлены: независимый повтор после откладывания (в том числе однократного будильника), проверка разрешения точных сигналов и повторное включение после возврата из настроек, защита от повторного запуска воспроизведения.

## Сборка APK
Проект использует Android Gradle Plugin 8.7.3, Kotlin 2.0.21, Gradle 8.10.2, JDK 17 и Android SDK 35.

Для GitHub Actions загрузите все файлы, включая `.github/workflows/build-apk.yml`, с сохранением структуры и запустите workflow **Build DARLY APK**. Результат: artifact `DARLY-debug-apk`.

## Важно
Не удалось выполнить компиляцию и тесты на физическом устройстве в текущей среде: отсутствуют Android SDK/Gradle и сетевой доступ для их установки. Это непроверенный прототип. HyperOS может ограничивать полноэкранные уведомления и фоновую работу; настройте разрешения вручную. Не используйте как единственный будильник до проверки.
