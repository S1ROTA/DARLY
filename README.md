# DARLY — Android Alarm

DARLY 2.8.0 Ambient Edition. Локальный будильник с одиночными сигналами, сериями, пресетами, несколькими таймерами и секундомером.

## Оформление

В разделе «Настройки → Оформление» доступны весна, лето, осень, зима, автоматическая сезонная тема и загрузка собственного изображения. Фотография сохраняется локально в приватном хранилище приложения. Цвет акцента подбирается автоматически, а фон плавно масштабируется, если анимации включены.

## Сборка

GitHub Actions: `.github/workflows/build-apk.yml` — тесты, Android Lint, `assembleDebug`, публикация артефакта `DARLY-debug-apk`.

## Ограничения

На Android 12+ требуется разрешение точных будильников; на Android 13+ — разрешение уведомлений. На HyperOS рекомендуется разрешить автозапуск и отключить ограничения батареи для приложения.

Системное уведомление Android нельзя произвольно анимировать; пульсация реализована на экране звонка.

Изменения см. в `CHANGELOG.md`.
