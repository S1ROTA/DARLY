# DARLY · Android Alarm

**DARLY 2.9.0 — Interface Polish & Trumpet** · Android 8.0+.

Локальный будильник с одиночными сигналами, сериями (например, 04:30, 04:40, 04:50…), пресетами, несколькими независимыми таймерами и секундомером.

## Интерфейс

- Единые размеры кнопок и реальные отступы между кнопками в горизонтальных рядах.
- Единый набор векторных иконок нижней панели, размер 28 dp.
- Компактный цифровой выбор времени: две прокручиваемые колонки часов и минут, со звуковым и тактильным откликом, если они включены в настройках.
- В настройках внизу показаны только название и версия приложения.

## Темы и фотографии

Весна, лето, осень, зима, автоматическая сезонная тема, своя фотография из галереи. Оригинальный файл сохраняется без перекодирования в приватное хранилище приложения. Для отображения фото декодируется под разрешение экрана с небольшим запасом для анимации; исключено прежнее принудительное уменьшение вдвое (`inSampleSize=2`). Очень большие изображения ограничиваются по размеру *отображаемого* bitmap ради памяти устройства — исходный файл сохраняется неизменным.

## Звуки

В редакторе одиночного будильника и серии доступны системная мелодия, пользовательский аудиофайл и встроенная **«Труба · Бодрое утро»**. Кнопка «Прослушать» воспроизводит выбранный звук; при звонке мелодия повторяется и подчиняется настройке плавного увеличения громкости. Встроенный трек хранится в `app/src/main/res/raw/wake_up_trumpet.mp3`.

## Сборка и проверка

GitHub Actions (`.github/workflows/build-apk.yml`): тесты, Android Lint, `assembleDebug`, артефакт **DARLY-debug-apk**. Код совместим с minSdk 26 / targetSdk 35, но функциональность звонка и фоновых будильников на POCO/HyperOS требуется проверить на самом устройстве.

На Android 12+ нужно разрешение для точных будильников, на Android 13+ — для уведомлений. В настройках HyperOS нужно отдельно разрешить автозапуск и отсутствие ограничений батареи.
