# DARLY 3.0.0 · Suburban Timetables

DARLY — автономный Android-будильник (Android 8+): одиночные сигналы, серии, пресеты, таймеры, секундомер и темы оформления.

## Новая вкладка «Электрички»

В DARLY появился **самостоятельный** раздел пригородного расписания. Он никак не связан с будильниками:

- поиск электричек между двумя станциями на выбранную дату;
- выбор станций из каталога Яндекс Расписаний и ручной ввод кода `s...`;
- дата, время отправления/прибытия, номер поезда и продолжительность;
- сохранение избранных направлений на устройстве;
- постраничная загрузка результатов и отображение ошибок сети;
- ссылка и подпись источника данных.

**Раздел не создаёт, не переносит, не изменяет и не удаляет будильники.** При недоступном интернете установленные сигналы продолжают работать как раньше.

### Доступ к API Яндекс Расписаний

Запросы: `https://api.rasp.yandex-net.ru/v3.0/search/` с фильтром `transport_types=suburban`. Ключ передаётся HTTPS-заголовком `Authorization`, вводится в приложении и хранится только в приватных настройках на телефоне; ключ не входит в исходники и APK.

Список станций загружается из `stations_list/` **только вручную**; у Яндекса JSON может быть около 40 МБ. На устройстве сохраняется компактный локальный каталог пригородных станций. После этого поиск по названию не требует повторной загрузки каталога. Можно также ввести код станции вручную (формат `s1234567`).

Ключ: https://developer.tech.yandex.ru/ (API Яндекс Расписаний).

**Юридическое ограничение:** условия бесплатного API допускают использование в открытых бесплатных приложениях для неограниченного круга пользователей; для частного использования DARLY потребуется согласовать допустимость с Яндексом или получить подходящий доступ. Код добавлен, но реальные ответы нельзя проверить без действующего ключа.

Документация: https://yandex.ru/dev/rasp/doc/ru/reference/schedule-point-point и https://yandex.ru/dev/rasp/doc/ru/reference/stations-list.

## Остальные возможности DARLY

- Рабочие серии: любое время начала, шаг, число сигналов и дни недели.
- Пресеты серии и отдельного сигнала.
- Несколько таймеров и секундомер с результатами.
- Фоны: весна, лето, осень, зима, сезонная тема и собственная фотография.
- Системная мелодия, импорт аудио и встроенная «Труба · Бодрое утро».

## Сборка

GitHub Actions `.github/workflows/build-apk.yml`: модульные тесты, Android Lint, `assembleDebug`, артефакт `DARLY-debug-apk`.

Разрешения: INTERNET для запросов расписания, точные будильники для сигналов, уведомления для отображения оповещений. Проверяй срабатывание будильников отдельно на устройстве POCO / HyperOS.
