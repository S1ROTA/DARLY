# DARLY · Android Alarm

**DARLY 2.5.1 — Cinematic Edition** · Android 8.0+ (minSdk 26), targetSdk 35.

Локальный будильник на системном `AlarmManager.setAlarmClock`. Не требует облака и аккаунта.

## Основные функции

- **Одиночные будильники:** время, дни недели, мелодия, вибрация, нарастание громкости и повтор сигнала.
- **Серии:** создай 2–24 самостоятельных системных будильника с интервалом 1–120 минут. Всё расписание хранится как единая управляемая серия. Любую серию можно включить, отключить, отредактировать или удалить целиком.
- **Рабочее утро:** готовый пример на будние дни — с 04:30 до 05:40 каждые 10 минут (8 сигналов). Можно изменить время, дни, шаг и количество.
- **Пресеты:** отдельные многоразовые шаблоны единичных будильников и целых серий. Применение шаблона создаёт новое расписание; сам шаблон не меняется.
- **Темы:** семь фоновых иллюстраций (реалистичные сезоны и оригинальные игровые арты), автоматическая сезонная тема.
- **Интерфейс:** тёмные полупрозрачные панели, отклик кнопок, предпросмотр серии; смена состояния будильников обновляется по событию, а не полным циклическим обновлением экрана.
- **Экран звонка:** на весь экран через категорию ALARM и full-screen intent, действия «Отложить» и «Остановить».

> Важно: на Android 12+ приложению нужен доступ к **точным будильникам**. На HyperOS также проверь автозапуск и режим батареи «Без ограничений». Android и прошивка могут блокировать фоновое отображение звонка.

## Сборка

Запусти GitHub Actions: `.github/workflows/build-apk.yml`. Процесс собирает проект Gradle 8.10.2 / JDK 17 / Android SDK 35, запускает тесты `:app:testDebugUnitTest`, проверку `:app:lintDebug`, затем `:app:assembleDebug`. Артефакт: `DARLY-debug-apk`.

APK собирается автоматически при обновлении ветки `main`. Готовый APK доступен на вкладке **Actions → успешная сборка → Artifacts → DARLY-debug-apk**. Для предварительного релиза используется тег `v2.5.2` и автоматическая публикация GitHub Release.

## Лицензии изображений

Фоны были созданы специально для этой версии генеративной графикой; это оригинальные стилизованные иллюстрации, а не изображения, извлечённые из Deadlock/Minecraft. Названия игр используются только для ориентира по эстетике. Официальные игровые ассеты и логотипы в приложение не включены.
