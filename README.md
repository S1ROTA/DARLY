# DARLY 3.1.0 · Electric Trains UX

DARLY — бесплатный Android-будильник (Android 8.0+) с сериями, пресетами, несколькими таймерами, секундомером и отдельной вкладкой расписания электричек.

## Электрички

Раздел **полностью независим от будильников**: не создаёт, не удаляет и не переносит сигналы.

- Если ключа нет, вкладка содержит только форму для ввода API-ключа Яндекс Расписаний. После сохранения открываются поиск и расписание.
- Изменить или удалить ключ: **Настройки → Электрички · Яндекс Расписания → Изменить или удалить API-ключ**. Ключ хранится в приватных настройках Android и не попадает в исходники.
- Компактный поиск: две станции, обмен направления, дата, кнопка «Сегодня», избранное и рейсы с отправлением/прибытием.
- Список станций: **автоматическая первая загрузка** после сохранения ключа, без отдельной кнопки и без ручной установки. Публичный API Яндекса не даёт универсального поиска станций по тексту; `stations_list/` возвращает ~40 МБ. DARLY скачивает и потоково разбирает список, сохраняя *временный локальный индекс только пригородных станций*. После этого автопоиск идёт на устройстве, без сетевых запросов на каждую букву.
- Временный локальный индекс автоматически обновляется через 7 дней, а при необходимости вручную из настроек. При ошибке сети доступна повторная попытка. Большой каталог **не распространяется вместе с APK**, чтобы не нарушать ограничения на повторное распространение данных.
- В качестве запасного способа можно ввести код станции `s1234567`.
- Запросы расписания выполняются через HTTPS `https://api.rasp.yandex-net.ru/v3.0/search/` с `transport_types=suburban`. Источник данных указан в интерфейсе.

**Использование Яндекс Расписаний регулируется условиями:** https://yandex.ru/legal/timetable_api/ru/ — полученные данные допускается хранить только временно для кэширования. Для запросов нужен собственный действующий ключ и сеть. Приложение не гарантирует актуальность и полноту расписания без проверки источника.

## Возможности будильника

- Одиночные сигналы и рабочие серии с заданным шагом;
- сохраняемые пресеты серий и одиночных сигналов;
- уведомления, вибрация, повтор сигнала, выбор мелодий, включая «Труба · Бодрое утро»;
- независимые таймеры и секундомер;
- сезонные и пользовательские обои.
