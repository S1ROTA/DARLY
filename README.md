# DARLY 2.6.0 · Time Suite

Локальный Android-будильник, серии сигналов, таймеры и секундомер. Android 8.0+ (`minSdk 26`, `targetSdk 35`). Интернет, аккаунт и облако не требуются.

## Возможности

- **Будильники и серии:** одиночные сигналы, несколько будильников через заданный интервал, пресеты рабочих графиков, дни недели и повтор сигнала.
- **Управление:** удалить одиночный будильник или серию без диалога подтверждения, выделять отдельные элементы, удалять выбранные или все сразу.
- **Строка состояния:** изображение фона продолжается за системными иконками; при наличии запланированных сигналов показывается постоянное уведомление с иконкой будильника и временем ближайшего сигнала (при разрешённых уведомлениях).
- **Таймеры:** любое количество независимых отсчётов, быстрое прибавление секунд/минут/часов, пауза, возобновление, сброс, удаление. Завершение через `AlarmManager.setExactAndAllowWhileIdle` даже вне приложения.
- **Секундомер:** монотонный отсчёт по `elapsedRealtime`; «Стоп» сохраняет очередную отметку и продолжает отсчёт, «Пауза» замораживает, «Сброс» очищает всю сессию и результаты.
- **Управление и стиль:** плавный переход между нижними вкладками, горизонтальные свайпы, звук нажатий и лёгкая вибрация с независимыми переключателями в настройках.
- **Темы:** оригинальные атмосферные игровые арты и реалистичные сезонные изображения.

Значок секундомера `◴` в правом верхнем углу открывает вкладки **Таймеры** и **Секундомер**.

## Важные разрешения

- **Точные будильники:** на Android 12+ открой настройки DARLY и разреши точные сигналы. Без этого и будильники, и таймеры не могут гарантировать точное завершение.
- **Уведомления:** на Android 13+ разреши уведомления, иначе иконка и сообщение о следующем сигнале, а также уведомление о завершении таймера, могут не отображаться.
- **HyperOS / POCO:** включи автозапуск и работу без ограничения батареи, особенно если будильник критически важен.

## Сборка на GitHub

Используй workflow **Actions → Build and Release DARLY**. Он выполняет `:app:testDebugUnitTest`, `:app:lintDebug`, `:app:assembleDebug` и прикладывает собранный `app-debug.apk` как артефакт **DARLY-debug-apk**.

Для публикации релиза используется git-тег `v2.6.0` и автоматическая страница GitHub Release. Изменения смотри в [CHANGELOG.md](CHANGELOG.md).
