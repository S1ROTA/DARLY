# DARLY 3.4.0 · Электрички рядом

Поиск показывает предстоящие рейсы; ушедшие раскрываются отдельной кнопкой. Кнопка «Отслеживать» закрепляет один выбранный рейс в уведомлении: маршрут, отправление, прибытие и обратный отсчёт. Нажатие открывает остановки, отмена доступна из уведомления и карточки рейса. Это сведения расписания, а не геолокация поезда; этапы уведомления обновляются системным неточным таймером, без постоянного фонового сервиса.

DARLY — бесплатный Android-будильник (Android 8.0+) с сериями, пресетами, несколькими таймерами, секундомером и отдельной вкладкой расписания электричек.

В версии 3.3 поиск станций выполняется в фоне, дни будильника показывают ближайшие даты, а экран звонка получил анимацию и движущуюся кнопку отложения. Движение и отложение при выключении экрана настраиваются отдельно; кнопка остановки остаётся на месте. Для немедленного показа поверх блокировки нужны системные разрешения на точные будильники, уведомления и полноэкранный сигнал. На HyperOS также проверь разрешения показа на экране блокировки и запуска из фона.

## Электрички

- Карточка рейса открывает экран с остановками, временем прибытия/отправления, платформами и выделением посадки/выхода. Можно переключиться между выбранным участком и полным маршрутом.
- Цена на выбранном участке берётся из `tickets_info.places` ответа `search/`, с точным учётом копеек и валюты. Если источник не передал тариф, цена не придумывается: есть явное состояние и переход в Яндекс Расписания.
- Полный список остановок загружается официальным методом `thread/` по UID рейса и дате его отправления. Ключ не передаётся во внешний браузер.

Раздел **полностью независим от будильников**: не создаёт, не удаляет и не переносит сигналы.

- Если ключа нет, вкладка содержит только форму для ввода API-ключа Яндекс Расписаний. После сохранения открываются поиск и расписание.
- Изменить или удалить ключ: **Настройки → Электрички · Яндекс Расписания → Изменить или удалить API-ключ**. Ключ хранится в приватных настройках Android и не попадает в исходники.
- Компактный поиск: две станции, обмен направления, дата, кнопка «Сегодня», избранное и рейсы с отправлением/прибытием.
- Список станций: **автоматическая первая загрузка** после сохранения ключа, без ручной установки. `stations_list/` возвращает ~40 МБ JSON. DARLY разбирает ответ потоково и сохраняет временный локальный индекс железнодорожных станций. Важно: большинство станций электричек имеют основной тип `train`, поэтому индекс учитывает и `train`, и `suburban`. Само расписание по-прежнему фильтруется по `suburban`.
- Загрузка выполняется одной задачей на процесс приложения и переживает пересоздание Activity; отображается объём разобранных данных (не размер сетевого трафика). После остановки процесса незавершённая загрузка начинается заново при следующем открытии раздела.
- Поиск учитывает «е/ё», пробелы и дефисы; подписи содержат населённый пункт и регион. Выбранный маршрут сохраняется между запусками.
- Ввод API-ключа проверяется до сетевого запроса: поясняющий текст, пробелы внутри и не-ASCII символы не принимаются.
- Временный локальный индекс автоматически обновляется через 7 дней, а при необходимости вручную из настроек. При ошибке сети доступна повторная попытка. Большой каталог **не распространяется вместе с APK**, чтобы не нарушать ограничения на повторное распространение данных.
- В качестве запасного способа можно ввести код станции `s1234567`.
- Запросы расписания выполняются через HTTPS `https://api.rasp.yandex-net.ru/v3.0/search/` с `transport_types=suburban`. Источник данных указан в интерфейсе.

**Использование Яндекс Расписаний регулируется условиями:** https://yandex.ru/legal/timetable_api/ru/ — полученные данные допускается хранить только временно для кэширования. Для запросов нужен собственный действующий ключ и сеть. Приложение не гарантирует актуальность и полноту расписания без проверки источника.

## Возможности будильника

- Одиночные сигналы и рабочие серии с заданным шагом;
- сохраняемые пресеты серий и одиночных сигналов;
- уведомления, вибрация, повтор сигнала, выбор мелодий, включая «Труба · Бодрое утро»;
- независимые таймеры и секундомер;
- сезонные и пользовательские обои.

## Интерфейс 3.2

Обновлены поверхности карточек, шрифтовая иерархия, состояния кнопок и выделение нижней навигации. Станции расположены вертикально, чтобы длинные названия не терялись. Новые сезонные пейзажи созданы ImageGen и включены в APK; для них не нужна сеть.

Заставка холодного запуска использует оригинальный векторный знак DARLY, нативную орбитальную анимацию и плавное появление фонового изображения. Подготовка обоев выполняется в фоне. При отключении анимаций и при активном звонке заставка пропускается/ускоряется; тёплый запуск не задерживается. Фоновая анимация циклична и отменяется при удалении View.

## Сборка

GitHub Actions в `.github/workflows/build-apk.yml`: `:app:testDebugUnitTest`, `:app:lintDebug`, `:app:assembleDebug`; итоговый артефакт `DARLY-debug-apk`.

История изменений — [CHANGELOG.md](CHANGELOG.md); тесты — [TESTING.md](TESTING.md).

Для безопасной проверки на устройстве есть вариант `qa` (`:app:assembleQa`), устанавливаемый отдельным приложением `com.darly.alarm.qa`. Он не заменяет рабочий DARLY и имеет отдельные настройки.
