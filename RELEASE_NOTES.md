# DARLY 3.0.0 — Электрички

Четвёртая вкладка «Электрички» — самостоятельный поиск пригородного расписания по двум станциям и дате через API Яндекс Расписаний v3.0.

Новые функции: выбор станции по названию из отдельного каталога или вручную по коду, избранные маршруты, времена отправления и прибытия, пагинация, указание источника, ввод личного ключа API.

Изменения не влияют на будильники и их расписания. Между расписанием электричек и сигналами нет никаких действий или общего хранилища.

Для работы необходим ключ API и интернет. Большой список станций загружается только по команде пользователя. Реальные сетевые ответы требуют проверки с действующим ключом и с соблюдением условий Яндекса.

Сборка и тесты должны пройти через GitHub Actions после отправки исходников; до этого версия не считается собранной.
