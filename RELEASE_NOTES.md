# DARLY 3.1.0 — Электрички без лишних экранов

- Если ключ Яндекс Расписаний отсутствует, вкладка «Электрички» показывает только ввод ключа.
- Ключ переносится в общие настройки: заменить или удалить можно в «Настройки → Электрички».
- Компактные кнопки выбора станций, даты и избранного, удобный список отправлений.
- Каталог станций электричек загружается автоматически один раз после ввода ключа, потоково разбирается и кэшируется временно (7 дней) на устройстве; ручная загрузка больше не нужна. Повторить и обновить можно из интерфейса.
- Отдельная логика расписаний полностью изолирована от будильников.
- JUnit-тесты жизненного цикла временного локального кэша.

API-ключ в APK не встроен. Первая загрузка каталога может потребовать около 40 МБ данных (размер исходного ответа Яндекса до сжатия); для реального поиска и проверки требуется действующий ключ.
