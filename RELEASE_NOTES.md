# DARLY v2.5.0 — Cinematic Edition

**Полностью новое оформление и настоящие серии будильников для рабочего утра.**

### Что нового
- **Новый интерфейс** — сдержанные тёмные карточки, мягкая анимация нажатия, удобная нижняя навигация.
- **Реалистичные сезонные фоны** и оригинальные игровые иллюстрации, вдохновлённые Deadlock / Minecraft (без сторонних игровых ассетов).
- **Серии будильников** — например, с 04:30 каждые 10 минут, 8 сигналов до 05:40 по будням.
- **Управление серией целиком** — изменить, включить/выключить, посмотреть все времена, удалить.
- **Пресеты** — сохраняй серии и отдельные будильники как многоразовые шаблоны.
- Следующий будильник теперь определяется по **реальному ближайшему времени срабатывания**.
- Улучшена обработка двух сигналов подряд: новый сигнал не пропускается, если предыдущий ещё играет.
- Энергоэффективное обновление экрана по событиям, без постоянной перерисовки.
- Добавлены автоматические тесты расчёта времени серий и перехода через полночь.

### Обновление

Устанавливается поверх DARLY 2.4 (одинаковый `applicationId`). Важно: APK из GitHub Actions подписан отладочным ключом. Если ключ сборки изменится, Android может потребовать удалить прежнюю версию, что приведёт к удалению локальных будильников. Перед удалением приложения запиши расписание.

### Разрешения

Для Android 12+ включите **Точные будильники**; на POCO / HyperOS — автозапуск, уведомления, полноэкранные оповещения и работу без ограничений батареи.

> **Статус:** предварительная сборка (debug). Проверка на реальном устройстве и сборка GitHub Actions необходимы до объявления стабильного выпуска.
