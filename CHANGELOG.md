# DARLY — история изменений

## 2.8.0 — Ambient Edition (предварительная версия)

- Исправлены скачки элементов при переключении вкладок: больше нет наложения двух полноэкранных корневых экранов; анимируется только прозрачность нового содержимого.
- Удалена дублирующая кнопка настроек из верхней панели; раздел «Настройки» остаётся в нижней навигации.
- В редакторах одиночного будильника и серии используется компактный цифровой выбор времени с колесами (spinner) вместо аналогового циферблата.
- Удалены игровые и неоновые профили из списка тем. Остались сезоны и автоматическая сезонная тема.
- Добавлена загрузка собственной фотографии через системный выбор файлов. Изображение копируется в приватное хранилище DARLY.
- Для собственной фотографии выбирается цвет акцента по пикселям изображения; панели сохраняют тёмный контраст.
- Добавлено плавное масштабирование фонового изображения (однократный медленный цикл) с учётом отключённых системных анимаций.
- На экране активного звонка добавлена мягкая пульсация индикатора. Системные уведомления анимируются самой ОС — произвольную анимацию внутрь уведомления Android не гарантирует.
- Унифицированы размеры интерактивных элементов через дизайн-систему Ui.

### Ограничения проверки

Исходники подготовлены, но Android SDK/Gradle в текущей среде отсутствуют. Необходимо выполнить GitHub Actions (`testDebugUnitTest`, `lintDebug`, `assembleDebug`) до установки в качестве основного будильника.
