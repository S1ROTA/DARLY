# История версий DARLY

## [2.5.2] — 2026-10-26 — Исправление регистрации событий Android

- Исправлена ошибка Android Lint `UnspecifiedRegisterReceiverFlag` в `MainActivity`.
- На Android 13+ (`API 33+`) внутренний `ALARMS_CHANGED`-приёмник регистрируется с `RECEIVER_NOT_EXPORTED`, чтобы другие приложения не могли отправлять ему события.
- Для Android 8.0–12L (`API 26–32`) сохранён совместимый вариант `registerReceiver`; локальное подавление Lint снабжено объяснением и не скрывает остальные ошибки анализа.
- Сборка по-прежнему обязана успешно пройти модульные тесты и Android Lint до создания APK.
- README очищен от инструкции по локальному терминалу, как и в версии 2.5.1.
- `versionCode = 10`, `versionName = 2.5.2`.


## [2.5.1] — 2026-10-26 — Исправление совместимости Android 8.0

- Исправлены вызовы `setShowWhenLocked` и `setTurnScreenOn` для устройств с API 26. На Android 8.0 используются совместимые флаги окна; на API 27+ — современные методы.
- Удалены локальные инструкции командной строки из публичного README. Описание сборки теперь ориентировано на GitHub Actions.
- Добавлена автоматическая загрузка отчёта Android Lint даже при ошибке проверки, чтобы проще находить все замечания.
- Увеличены `versionCode` (9) и `versionName` (2.5.1).


## [2.5.0] — 2026-10-26 — Cinematic Edition

### Интерфейс и темы
- Полностью переработаны главный экран, экраны пресетов, создания и изменения будильников, звонка, настроек и тем.
- Взрослый тёмный визуальный стиль с прозрачными карточками, тонкими границами и сдержанной типографикой.
- Заменены семь фоновых изображений: реалистичные четыре сезона, оригинальные иллюстрации в игровой стилистике для Deadlock, Minecraft и Neo Dark.
- Добавлена плавная анимация нажатия кнопок; можно отключить в настройках.
- Нижняя навигация для будильников, пресетов и настроек; учёт системных панелей Android.

### Серии и пресеты
- Новая сущность «Серия будильников»: первый сигнал, интервал, количество, дни недели, название, звук, вибрация, повтор и нарастание громкости.
- Пример: рабочие будни, 04:30 — 05:40, 8 будильников с шагом 10 минут.
- Создание отдельных точных системных будильников на каждый шаг серии (не полагаемся на snooze для следующих сигналов).
- Общее управление: включить/отключить, изменить, показать расписание, удалить всю серию.
- Отдельное хранилище многоразовых пресетов серий и одиночных сигналов.
- Корректный перенос маски дней недели у серий, переходящих через полночь.

### Исправления и производительность
- Следующий сигнал вычисляется по ближайшему будущему срабатыванию с учётом дней недели.
- Фоновое изображение теперь показывает ImageView через ресурс, без ручного декодирования Bitmap на каждом экране.
- Событийное обновление списков и часов — только один раз в минуту на открытом главном экране.
- Удаление серии отменяет её системные будильники и отложенные сигналы.
- Исправлена генерация идентификаторов сохранённых одиночных пресетов.

### Тесты и сборка
- Добавлен независимый от Android алгоритм `SeriesSchedule`.
- 6 модульных тестов: рабочая серия, смена дня после полуночи, уникальность 24 сигналов и проверки неверных значений.
- В GitHub Actions перед сборкой APK добавлен шаг `:app:testDebugUnitTest`.

### Обратите внимание
- Android 12+ требует отдельного разрешения для точных будильников.
- Тестирование на реальном POCO/HyperOS необходимо: разрешения, работа при блокировке, рестарт телефона, энергосбережение и уведомления.
- Смена разрешения на точные будильники запускает повторную регистрацию сигналов после возврата в приложение.
- В настройках Android 14+ появилась кнопка разрешений полноэкранного сигнала.
