# История версий DARLY

## [3.1.0] — 2026-10-27 — Электрички: быстрый интерфейс и поиск станций

- **Первый запуск без API-ключа:** вместо элементов расписания показаны только ввод ключа и кнопка сохранения.
- **Ключ перенесён в общие настройки:** его можно изменить или удалить в «Настройки → Электрички · Яндекс Расписания»; в рабочем разделе кнопки управления ключом нет.
- **Компактная вкладка:** поля станций расположены рядом, обмен местами между ними, дата/«Сегодня»/избранное — одна строка, маршруты в горизонтальном списке, плотнее карточки отправлений.
- **Поиск станций без ручного скачивания:** Яндекс не предоставляет текстовый автопоиск станций в публичном API; после добавления ключа каталог загружается автоматически в фоновом потоке, парсится потоково и сохраняется в виде компактного частного индекса только пригородных станций.
- Временный индекс обновляется после 7 дней (без повторных 40 МБ при каждом запуске), доступен повторный запрос при сетевой ошибке и ручное обновление в настройках. Исходный каталог не включён в APK.
- Поиск по названию отдаёт приоритет совпадению с началом названия, ограничивает число подсказок, сохраняет ввод при завершении фоновой загрузки.
- Аварийный ввод кода станции оставлен на экране выбора станции. Будильники с расписанием не связаны.
- Новые JUnit-тесты срока действия локального кэша.

## [3.0.0] — 2026-10-27 — Электрички (отдельный раздел)

- Добавлена самостоятельная четвёртая вкладка «Электрички» в нижней навигации.
- Поддержка Яндекс Расписаний API v3.0: маршруты электричек на дату (`transport_types=suburban`), время отправления и прибытия, номера и длительности, пагинация.
- Выбор пригородных станций из сохранённого на устройстве каталога; загрузка большого списка станций запускается только вручную.
- Ввод кода станции `s…` без обязательной загрузки каталога.
- Локальные избранные маршруты и отдельные настройки ключа API без публикации в GitHub.
- Добавлено разрешение INTERNET и отображение источника данных.
- **Никакой связи расписания с будильниками:** сигналы не создаются, не изменяются и не удаляются разделом электричек.
- Добавлены тесты формата станции, даты и различия станций маршрута.

## 2.9.0 — Interface Polish & Trumpet (предварительная версия)

### UI
- Исправлена ошибка использования вертикального `Ui.space` внутри горизонтальных рядов: прежде большинство пар кнопок разделял только 1px. Добавлены специальные горизонтальные отступы не менее 12dp.
- Primary и outline-кнопки приведены к одной высоте 54dp и одинаковым паддингам.
- В нижней панели эмодзи/Unicode-иконки заменены тремя векторными иконками 28dp; одинаковые зоны нажатия, подписи 12sp.
- В настройках убраны пояснения о POCO/HyperOS и слоган — оставлено «DARLY 2.9.0».
- Стандартный высокорослый `TimePicker` заменён компактным `CompactTimePicker` на двух `NumberPicker` (24 часа и 60 минут) с обратной связью `CLOCK_TICK` и кликом при смене значения. Отклик можно выключить в настройках.

### Обои
- Исправлен жёсткий `inSampleSize = 2` для пользовательских обоев, который снижал их детализацию вне зависимости от разрешения устройства.
- Добавлены кэширование и подбор декодируемого bitmap под размер экрана, 12% запас для анимации и ограничение 16 Мп для экстремально больших файлов.
- Исходное изображение копируется без изменения байтов и не пережимается в JPEG; уменьшение затрагивает только bitmap для экрана.
- Для пользовательских фотографий ослаблена затемняющая накладка и уменьшено масштабирование фона, чтобы не портить чёткость.

### Музыка
- Добавлен встроенный `wake_up_trumpet.mp3` (пользовательский аудиофайл) как выбираемая мелодия «Труба · Бодрое утро».
- В редакторе одиночного будильника и серии появился общий блок мелодий: встроенная, системная и собственный аудиофайл, с кнопкой прослушивания.
- `RingService` обрабатывает встроенный идентификатор `darly:sound:trumpet` и передаёт ресурс в MediaPlayer. Мелодия повторяется при звонке; плавная громкость работает как раньше.

### Проверка
- `WallpaperSize` компилируется отдельно стандартным компилятором Kotlin, проверены сценарии камерных и маленьких фото; добавлены JUnit-тесты размеров.
- Проверены XML-ресурсы, ZIP и метаданные загруженного MP3. Полная Android-компиляция и тест на устройстве ожидают GitHub Actions.
