# DARLY 2.6.0 — проверки

## Выполнено локально
- Компилируемые JVM smoke-тесты чистых функций `TimerMath`: интервал до окончания, обрезка отрицательных значений, формат времени больше 24 часов, сотые секунды и разница отметок секундомера.
- Анализ синтаксических сообщений компилятора Kotlin без Android SDK (проверка **не равнозначна** сборке приложения).
- Проверки наличия receiver, notification permission, сброса и сохранения состояния.

## Требуется GitHub Actions
1. `:app:testDebugUnitTest` (включая `TimerMathTest`).
2. `:app:lintDebug` (в особенности уведомления и совместимость API 26/33/35).
3. `:app:assembleDebug` и сохранение APK.

## Тестирование на устройстве
- Цвет системной строки и видимость иконок.
- Уведомление о ближайшем будильнике и отмена уведомления после удаления.
- Удаление одного, нескольких и всех сигналов, включая серии.
- Запуск трёх таймеров одновременно; завершение при свёрнутом и закрытом приложении, после перезагрузки, при отключённых уведомлениях и без разрешения точных сигналов.
- Секундомер: несколько «Стоп», пауза/продолжение, сброс и восстановление после закрытия.
- Анимации вкладок, свайпы, звук кнопок, вибрация и переключатели настроек.
