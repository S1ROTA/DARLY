# План проверки DARLY 3.0.0

## GitHub Actions

1. `:app:testDebugUnitTest`: тесты даты и кода станций и прежние тесты будильников/таймеров.
2. `:app:lintDebug`: в частности проверка разрешения `INTERNET`, Android 8+ и визуальных ресурсов.
3. `:app:assembleDebug`: выпуск APK.

## Ручные проверки на Android

1. Открыть вкладку «Электрички», открыть настройку ключа, сохранить ключ и вернуться.
2. Без каталога выбрать станцию вручную по коду `s…`; убедиться, что некорректный код не принимается.
3. По отдельному нажатию загрузить каталог станций (до ~40 МБ). Найти разные платформы по названиям, включая «Хотьково».
4. Выбрать две станции, дату, загрузить расписание. Сравнить с rasp.yandex.ru, в том числе часовой пояс и сезонные изменения.
5. Проверить пустую выдачу, выключенный интернет, неверный ключ, превышение квоты и постраничную загрузку.
6. Сохранить направление в избранное; перезапустить приложение и проверить сохранность.
7. Перейти во вкладку «Будильники». Установленные сигналы и серии не должны изменяться при любых действиях во вкладке «Электрички».
8. Проверить будильник с заблокированным экраном на устройстве POCO / HyperOS.

Наличие функций и проверка ZIP не являются подтверждением реальных ответов API или безошибочной сборки APK.
